# 链接唤醒（linkwake）

条目里的资源通常不是**一个**能直接点的链接，而是三四条堆在一起：磁力一条、
`.torrent` 一条、阿里云盘和百度网盘各一条，提取码还写在摘要正文里。想下的时候
得先点开详情、一条条复制、再切到客户端粘贴，中间还要人肉对提取码。

这个插件把这段路缩短成「点一下」。

- **认得出**：25 个提供方（网盘 19 家、BT 类 4 种、直链、网页）
- **补得上**：百度网盘缺 `pwd` 时，从摘要里找「提取码: xxxx」补进链接
- **交得出去**：系统默认程序、指定 exe、客户端协议、qBittorrent、aria2
- **说得清**：失败一定要给原因（协议没人接手 / 程序路径不对 / 只允许本机），不做「点了没反应」
- **连得上**：不是又一个孤岛页面 —— 点标题跳回主界面阅读区，点星就是主界面那颗星，
  主界面阅读区里的网盘链接也会多出「打开 XX 网盘」的按钮

在主程序 **2.1.2** 上开发与验证。更早的 2.1.x 没测过 —— 它用到的
`ctx.views` / `ctx.settings.define(after=...)` 是 2.1 系列的契约；
阅读区联动用的 `article:open` 扩展点是 2.1.2 才有的，装在 2.1.1 上插件照常可用，
只是阅读区那部分不出现。

---

## 装

把 `linkwake/` 整个目录放进主程序的插件目录：

```
AnimeRSSReader/
├── plugins/
│   └── linkwake/          ← 放这里
├── anime_rss/
└── dist/
```

或者用插件管理器装 `linkwake-1.2.0.zip`。装完重启，侧栏的 **工具** 里会多一张
「链接唤醒」卡片 —— 主程序从 2.1.3 起把插件都收在工具空间里，侧栏不再逐条平铺，
装多少个插件都占一行。

停用就是把它挪进 `plugins/.disabled/`（插件发现会跳过 `.` 与 `_` 开头的目录）。

**别在插件里顶层 import 非标准库模块。** exe 是单文件 PyInstaller 包，只带了主程序
真正用过的标准库；插件顶层 import 一个没打进去的模块会 `ModuleNotFoundError`，而
插件发现是整趟 `try` 的 —— 一个插件炸掉，所有插件一起消失。这个插件顶层只用了
`json / os / re / time / threading / subprocess / webbrowser / urllib`。

## 用

界面三块：上面筛选，中间**一条目一行**的列表，底部（勾选后）批量条。

**筛选**：「可下载 / 全部 / 磁力种子 / 网盘 / 直链 / 网页」。数字只标在**当前**那一档
上 —— 接口每次是按 `kind` 过滤后再统计的，给别的档标数字等于拿这一档的数量冒充那一档。

默认档（「可下载」）会筛掉 bgm.tv、资料站这类只是网页的链接，否则列表会被灌满。
想看全部就点「全部」。

**一行是一个条目**，不是一条链接：

```
☐ ● [黒ネズミたち] 少女與戰車 … - 04 (ABEMA 1920x1080 AVC AAC MKV)   度  种  链  ★ ⌄
     bangumi · 750.09 MB · 38 分钟前
```

- 左边勾选框选的是**整条**，不是某一条链接
- 标题点下去回到主界面的阅读区（同一条）
- 右边三个小徽章是「这条有几个来源」：`度` 百度网盘、`种` 种子、`链` 直链；
  徽章上的数字表示这一组里有几条
- 点行的空白处展开明细，**链接原文与「唤醒 / 复制」都在明细里** ——
  一条链接占一整行、还带一对按钮，70 条链接就是四千像素的滚动，浏览变成了体力活

**批量按条目算**：勾几个条目 → 复制 / 发到 qB / 发到 aria2 / 逐个唤醒 / 清空。
一个条目下的磁力、种子、网盘会**一起**进队列，网页地址自动跳过；一条能下的都没有时
直说「勾选的条目只有网页地址」，不装作成功。「复制」在前端做，不打接口。
批量条贴在窗口底部 —— 列表有四十行的时候，躺在最下面等于没有。

**设置抽屉**（右上「设置」）：每个提供方一行，选方式、填路径、填协议名；
下面两个表单配 qBittorrent 与 aria2，各带一个「测试」按钮。

## 与主界面联动

装了这个插件，主界面不只是多一个侧栏入口：

| 在哪 | 发生什么 |
|---|---|
| 链接唤醒 → 点标题 | 跳回主界面阅读区，打开同一条 |
| 链接唤醒 → 点星 | 调主程序的 `/api/star`，和主界面那颗星是同一份状态 |
| 主界面阅读区打开条目 | 插件订阅 `article:open`，给正文里的网盘链接加提供商角标，再补一个「打开 XX 网盘」按钮 |
| 主界面阅读区 | 网盘链接因此能直接交给客户端，不再只有「浏览器打开」 |
| **深度搜索 → 「下载」** | 把磁力 / 种子递过来，按你设的「优先响应」直接进 qB / aria2 / 系统客户端 |
| **侧栏快捷搜索** | 深度搜索认领了那条搜索框，回车直接出结果（这一条不归 linkwake 管，顺便提一句） |

只用到一个通用扩展点：主程序渲染完阅读区后 `emit("article:open")`。主程序**不认识
linkwake** —— 插件没装，那个事件没人听，界面跟以前一模一样。没有 if-else、
没有硬编码的插件 id，也没有「装了插件主界面才不报错」这种依赖。

角标只在插件加载时订阅一次，不随视图挂载/卸载 —— 否则从「链接唤醒」切回列表，
阅读区刚加的按钮就没了。

## 优先响应：点一下到底交给谁

上面那张表是「自动」时的细则。真正决定第一跳的是设置抽屉最上面的
**优先响应** —— 四种类型（磁力 / 网盘 / 直链 / 网页）各一行，可选：

| 选什么 | 效果 |
|---|---|
| 自动 | 按下面「每种链接交给谁」的逐条设置走（默认，等于老行为） |
| qBittorrent / aria2 | 直接进下载队列，能确认真的加进去了 |
| 系统默认程序 | 交给系统关联的那个客户端 |
| 浏览器打开 | 网盘链接会带上提取码 |
| 只复制链接 | 什么都不启动 |
| 每次都问我 | 点的时候弹一层，当场挑 |

选「每次都问我」之后，深度搜索的「下载」、阅读区的「打开 XX 网盘」、插件页里的
「唤醒」都会先弹同一个选择层：

```
┌────────────────────────────────────────┐
│ [度] 用什么打开？                    × │
│      百度网盘 · 网盘 · 某番 01          │
│ https://pan.baidu.com/s/1abc?pwd=k9x2  │
│ ┌────────────────────────────────────┐ │
│ │ ∘ 自动          当前：浏览器打开 默认│ │
│ │ ⇩ qBittorrent   还没填 qB 地址      │ │
│ │ ↗ 系统默认程序   交给系统关联的客户端│ │
│ │ ◎ 浏览器打开     网盘链接会带上提取码│ │
│ │ ⧉ 只复制链接     不启动任何程序      │ │
│ └────────────────────────────────────┘ │
│ ☐ 以后网盘都用它，不再问      改默认   │
└────────────────────────────────────────┘
```

勾上「以后都用它」就把这一项写进配置，下次不再问。没填地址的客户端会置灰并说明
原因（不是藏起来），因为「点了没反应」比「灰着并且写了为什么」更难查。

## 给别的插件用：`link.wake`

深度搜索只拿得到一个 URL，它不该为了「唤醒」再抄一份网盘域名表。所以能力在
主程序那一层登记，双方互不认识：

```js
// 别的插件这样用（没有 linkwake 时 can() 是 false，自己退回复制）
if (ARR.can("link.wake")) {
  ARR.invoke("link.wake", { url: "magnet:?xt=urn:btih:…", title: "某番 01" });
}
```

linkwake 收到后做三件事：`POST /api/linkwake/prepare` 认出这是谁、查优先响应、
该弹层就弹层。`ask: true` 可以强制「这一次让我选」，不影响配置。

主程序只提供 `ARR.provide / can / invoke` 这三个转发函数，**不认识任何具体能力名**。

## 每种链接默认交给谁

默认值是按「可靠性」排的，不是按「看起来高级」排的：

| 类型 | 默认方式 | 为什么 |
|---|---|---|
| 磁力 / eD2k / 迅雷链 / 种子 | 系统默认程序 | 一定有人认领，交给系统关联的 BT 客户端最省事 |
| 网盘（19 家） | 浏览器打开（带提取码） | 各家客户端协议时有时无，猜一个不可靠的协议名，用户看到的是「点了没反应」 |
| 直链 / 网页 | 浏览器打开 | 直链交给浏览器下载，网页就是网页 |

想让网盘走客户端，在设置里把该提供方改成「客户端协议」并填协议名
（百度是 `baiduyun`），或改成「指定程序」填 exe 路径 —— 这两种是可靠的，
因为协议名与路径是你自己填的。

支持的 25 个提供方：

- **国内网盘**：百度、阿里云盘、夸克、123 云盘、迅雷云盘、115、天翼、移动云盘、腾讯微云、UC、蓝奏云、PikPak、TeraBox、奶牛快传、文叔叔
- **海外**：Google Drive、OneDrive、MEGA、Dropbox
- **BT**：`magnet:` / `ed2k:` / `thunder:` / `.torrent`
- **兜底**：直链文件、网页

认不出的域名一律回落「网页」，只给「打开 / 复制」——**宁可少猜，不瞎猜**。猜错
成某个网盘的代价是用户点了以后跳到一个不存在的页面。

## 接下载器

两个客户端都是「能确认真的加进去了」的方式，和「唤醒」不同：唤醒只能证明
把链接递给了系统，加没加进队列只有客户端知道。

### qBittorrent

填地址（`http://127.0.0.1:8080`）、用户名、密码，点「测试」。插件走 Web API v2：
`POST /api/v2/auth/login` 带 `Referer`（不带会被拒），取 `Set-Cookie` 里的 SID，
再 `POST /api/v2/torrents/add`，多条链接用换行分隔放进同一个 `urls` 字段。

### aria2

填 RPC 地址（`http://127.0.0.1:6800/jsonrpc`）与令牌，点「测试」看版本号。
批量时**一条一次调用**：`aria2.addUri` 的数组语义是「同一个任务的多镜像」，
一次传一批磁力会被合并成一个任务。

**口令不回显。** 接口只返回 `passwordSet` / `tokenSet` 两个布尔值，页面上密码框
永远是空的。要改就重填，留空表示「不改」。这个页面可能被同网段的人打开
（主程序 `--lan` 模式），把口令原样发下去等于贴在墙上。

## 安全边界

这个插件的动作是**在你这台机器上启动进程**，所以护栏写在启动之前：

1. **只认本机**。默认只接受 `Host` 是 `127.0.0.1 / localhost / ::1` 的请求，
   局域网来源一律 403，并说明怎么放开。要放开得去设置里打开「允许局域网设备
   触发唤醒」，并且知道自己在做什么。
2. **协议白名单**。只放行 `http / https / magnet / ed2k / thunder`。`file:`、
   `javascript:`、`data:`、`smb:`、`about:`、`ms-msdt:`、`search-ms:` 之类一律拒绝；
   自定义协议必须在该提供方的配置里显式填过才放行。`\\host\share` 这种 UNC 路径
   也拒 —— 指向网络共享的可执行文件不该被「一键打开」。
3. **不经 shell**。`subprocess.Popen` 传参数列表，`shell=False`；参数模板
   `{url}` 里的链接只做字符串替换，不做命令拼接。
4. **不写系统状态**。不注册协议、不改注册表、不改文件关联。
5. **限制批量规模**。一次最多 200 条，超了明说，不悄悄截断。

「复制」不受第 1 条限制 —— 它不启动任何东西，远端也能用。

## 接口

都在 `/api/linkwake/` 下，不占公共路径；前端静态资源走 `/plug/linkwake/`。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/linkwake?kind=&q=&limit=` | 列表。`kind` ∈ `dl/all/bt/pan/file/web` |
| GET | `/api/linkwake/item/{iid}` | 单条详情（含详情页链接与全部链接） |
| POST | `/api/linkwake/prepare` | 点之前问一句：`{url, pid?, title?, ask?}` → 类型、默认目标、可选项 |
| POST | `/api/linkwake/wake` | 唤醒一条：`{url, target?}` 或老的 `{url, pid, mode?}` |
| POST | `/api/linkwake/batch` | 批量：`{action: copy\|open\|qb\|aria2, urls: []}` |
| GET | `/api/linkwake/apps` | 读配置（口令只回「有没有设」）+ 可选目标 |
| POST | `/api/linkwake/apps` | 存配置（口令 / 令牌留空表示不改）；也收 `prefs` |
| POST | `/api/linkwake/probe` | 测连通：`{which: qb\|aria2}` |

列表响应里的 `counts` 是**按当前 `kind` 过滤后**的统计，`scanned` 是这次扫了多少条
条目 —— 空列表时要靠它说清「扫了 40 条，一条可下的都没有」，而不是让用户以为坏了。

## 设置项

设置 → 链接唤醒（排在「搜索」之后）：

| 键 | 默认 | 说明 |
|---|---|---|
| `lwAllowRemote` | 关 | 允许局域网设备触发唤醒 |
| `lwAutoPwd` | 开 | 从摘要里补百度提取码 |
| `lwOnlyDownloadable` | 开 | 默认只看可下载的，筛掉纯网页 |
| `lwPageSize` | 40 | 每次列出条数（10~200） |

客户端地址 / 路径不在这里，在插件页面的设置抽屉里 —— 那是「这台机器上装了什么」，
跟着机器走，不该混进全局偏好。

配置存在 `<data_dir>/linkwake.json`，原子写（`.tmp` + `os.replace`）。文件坏了、
少了字段、多了没见过的键，都不会让插件起不来：读的时候逐字段合进默认值，认不出的
一概丢掉。

## 已知限制

- **只处理条目里已经有的链接**。摘要里写成「见评论区」「私信」的，插件无能为力。
- **提取码只对百度自动补**。其他网盘把码拼进 URL 的规则各家不同，猜错就是跳到
  错误页面，所以只显示码（卡片上「码 xxxx」），不擅自改 URL。
- **网盘不直接调客户端**。原因见上面「默认交给谁」。
- **qB / aria2 的连通性依赖它自己开着**。没开时提示「连不上，端口没人监听
  （客户端启动了吗？）」—— 这是本机地址绕过了系统代理之后的真实错误，
  不是 502。
- **不解析种子内容**。`.torrent` 只当链接交出去，不在插件里读文件列表。
- **阅读区角标与网盘按钮需要主程序 2.1.2**。它靠 `article:open` 扩展点；在 2.1.1 上
  插件本身完全正常，只是阅读区不会多出那部分。
- **「优先响应」只认本机的客户端**。qB / aria2 填的是本机地址时才用得上；
  填了远端地址（比如 NAS）也能连，但唤醒护栏仍然只管「谁在触发」，不管「连去哪儿」。
- **选择弹层不记「取消」**。关掉等于这次不做事，不会把偏好改成别的。

## 测试

```bash
# 后端：规则层、唤醒层、客户端、接口层
python -m unittest discover -s tests -q

# 前端：jsdom 里跑 view.js，断言点了以后有没有回音
npm i jsdom
node tests/check_view.js

# 只读自检（不启动任何程序、不写文件）
python selfcheck.py
python selfcheck.py --base http://127.0.0.1:8899   # 对着运行中的主程序（exe 也行）
```

四层各管一段，互不代替：

- `test_rules` —— 认域名、抽链接、补提取码。纯函数，每条规则一组正反例。
- `test_wake` —— 护栏。危险协议、UNC、控制字符必须被拒；`copy` 不启动进程。
- `test_clients` —— 起真 HTTP 服务假装 qB / aria2，验登录、`Referer`、SID、
  批量语义、错误提示。
- `test_module` —— 真起一个 `create_app()`，走 HTTP 语义。**测试里不真启动程序**：
  凡是会 `open` / `app` 的用例，都先把假 `Waker` 换进去，记录「想打开什么」。
- `check_view` —— 只测一件事：**点了有没有回音**。后端全绿而前端把 `r.ok` 判反，
  用户看到的还是坏界面。

自检里的「顶层 import 白名单」是静态扫描，比「这台机器上能不能 import」重要：
本机有 `platform` 不代表 exe 里有。

## 目录

```
linkwake/
├── __init__.py        包入口：延迟导入 + 绑定自己的目录
├── module.py          模块与路由：读库、拼响应、校验来源
├── rules.py           纯规则：认提供方、抽链接、补提取码（零副作用）
├── wake.py            真动手：交给系统 / 指定程序（护栏在这里）
├── clients.py         真回执：qBittorrent Web API 与 aria2 JSON-RPC
├── selfcheck.py       只读自检
├── static/
│   ├── view.js        视图脚本（ARR.registerView）
│   └── view.css       样式（走主程序 CSS 变量，跟随深浅色主题）
├── preview/
│   └── preview.html   离线预览：假数据 + 假侧栏，不连主程序也能看界面
└── tests/
    ├── _env.py        找主程序、起临时应用、塞条目
    ├── test_rules.py
    ├── test_wake.py
    ├── test_clients.py
    ├── test_module.py
    └── check_view.js
```

`preview/preview.html` 直接用浏览器打开即可：带 5 个假条目（覆盖磁力、种子、直链、
网盘、eD2k、迅雷链），`#theme` 切深浅色，`#again` 重放动画。改样式时用它比启动主程序快。
